PANTUNLINGO PROJECT ROADMAP
===========================
Last updated: 24 November 2026

PROJECT GOAL
------------
PantunLingo is a web-based learning system for creating, saving, reviewing, and managing Malay pantun. The system has three planned user roles:
- Student
- Lecturer
- Administrator

2. CURRENT DEVELOPMENT STATUS
=============================

The Student Draft Management module is working.

Current working flow:
1. Student opens Write Pantun.
2. Student writes a title and four pantun lines.
3. Student saves the pantun as a draft.
4. Draft is stored in the SQLite database.
5. Student opens My Drafts.
6. Student can see saved drafts.
7. Student can continue editing a draft.
8. Student can update the same draft.
9. Student can delete a draft after confirmation.

Important current limitation:
- The system currently uses a temporary development student ID: studentId = 1.
- There is no real registration, login, password security, or user session yet.
